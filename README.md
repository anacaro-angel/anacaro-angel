# Acerca de mí

Soy Ingeniera en proceso para certificarme como analista de datos. Tengo 6 años de experiencia en industrias multinacionales en donde ha ido creciendo mi interés y pasión por la data. 

Dentro de mi experiencia he visto que los datos son la base para la toma de decisiones por lo que he aprendido a generar insights que llevan a optimizar procesos y desarrollos. De esta manera me gusta trabajar con objetivos claros y orientar la toma de decisiones de una forma estrategica para beneficio del negocio. 

## Herramientas
* Análisis y gestión de datos: **Excel | Google Sheets | SQL | Python**
* Visualización de datos: **Power BI**

## Soft skills
